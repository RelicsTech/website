How to Clean-Install a GPU Driver

Old driver files can cause crashes, stutter and black screens. A clean install removes them before the new driver goes in.

  1. Download the new driver first. Get the latest driver from NVIDIA, AMD or Intel directly. Save the installer, then disconnect from the internet so Windows can't install its own.
  2. Get DDU. Download Display Driver Uninstaller from its official site (Wagnardsoft). Extract it to a folder.
  3. Boot into Safe Mode. Hold Shift while clicking Restart, then Troubleshoot, Advanced options, Startup Settings, and press 4 for Safe Mode.
  4. Run DDU. Choose your GPU brand and click "Clean and restart". Leave the default options on.
  5. Install the new driver. After the restart, run the driver installer you saved and pick a custom or clean installation if offered. Reconnect to the internet when it's done.

If the problem comes back, it can be heat, a failing card or a power issue. Open a ticket and we'll help you narrow it down.
