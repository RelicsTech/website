Clean a Disk with DiskPart

Warning: clean removes all partitions from the selected disk, making its files inaccessible. Back up anything you need before proceeding. Do not use this to troubleshoot a disk that contains files you want to recover.

Open Command Prompt or Terminal as administrator.

1. Start DiskPart: diskpart

2. List disks: list disk

3. Select the intended disk: select disk X (replace X with its disk number).

4. Verify the disk model, size and volumes: detail disk. Stop if you are unsure.

5. Only when you have confirmed the correct disk and your backup: clean

6. For a GPT setup, optionally run: convert gpt

For a new data partition only (not Windows system installation), optionally run:

create partition primary

format quick fs=ntfs

assign

exit

The assign command selects an available drive letter.

Microsoft: DiskPart clean

Microsoft: create partition primary
