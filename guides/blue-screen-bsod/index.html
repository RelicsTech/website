Blue Screen of Death: What to Do

A blue screen looks scary, but the stop code usually points to the cause. Follow these steps in order.

  1. Write down the stop code. Take a photo of the screen. Note the stop code, such as IRQL_NOT_LESS_OR_EQUAL or SYSTEM_SERVICE_EXCEPTION, and any file name shown.
  2. Undo recent changes. Think about what changed before the first blue screen: a new driver, program or part. Boot into Safe Mode and remove it or roll the driver back.
  3. Look at the crash dump. Windows saves crash files in C:\Windows\Minidump. A free tool like BlueScreenView shows which driver was involved.
  4. Repair the system files. Open Command Prompt as administrator and run sfc /scannow. Then run DISM /Online /Cleanup-Image /RestoreHealth and restart.
  5. Test the RAM and the drive. Bad memory and a failing drive are common causes. See our guide on testing RAM and check the drive with CrystalDiskInfo.
  6. Reinstall the graphics driver. If the stop code mentions video or nvlddmkm, do a clean GPU driver install as in our guide.

Send us the stop code and what you changed last in our Discord, and we will help you narrow it down.
