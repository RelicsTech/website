How to Test RAM for Errors

Faulty memory causes blue screens, crashes and corrupted files. A proper test takes a few minutes of work and some waiting.

  1. Turn off XMP first. Go into the BIOS and switch XMP or EXPO off. This shows whether the RAM works at its default speed.
  2. Run Windows Memory Diagnostic. Press Start, type Windows Memory Diagnostic, and choose to restart now. After the restart, Windows shows the result. It also saves it in Event Viewer.
  3. Use MemTest86 for a real test. Put MemTest86 on a USB stick, boot from it and let it run at least four passes. Any error means a faulty stick, slot or setting.
  4. Test one stick at a time. Take out all but one stick and test it. Then test each stick in the same slot, and then in another slot, to find the cause.
  5. Reseat the sticks. With the PC off and unplugged, remove the sticks and push them back in until both clips click.
  6. Replace what fails. If a stick errors in every slot, replace it, as most RAM has a long warranty. If every stick fails in one slot, the slot or the board is bad.

Not sure how to read the results? Post a photo of the MemTest86 screen in our Discord.
