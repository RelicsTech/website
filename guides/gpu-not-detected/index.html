Graphics Card Not Detected: What to Check

If Windows or the BIOS does not see the graphics card, the cause is often seating or power. Check these in order.

  1. Look in Device Manager and the BIOS. Open Device Manager and check Display adapters. In the BIOS, look for the card among the PCIe devices.
  2. Reseat the card. Power off, unplug, and push the card into the slot until the clip clicks. Make sure the card is screwed to the case.
  3. Check all power cables. Plug in every PCIe power connector of the card. Avoid splitters. With a 12-pin cable, push it in all the way.
  4. Check the monitor cable. The cable must be in the graphics card, not in the motherboard.
  5. Install the driver cleanly. Do a clean driver install as in our guide, so old files don't block the card.
  6. Update the BIOS and check PCIe. Update the BIOS. Make sure the slot is not set to a mode your card can't use, and turn on Above 4G Decoding if the board offers it.
  7. Test the card elsewhere. If you can, try the card in another PC. That shows whether the card or the system is at fault.
