BCU (Bulk Crap Uninstaller)

Bulk Crap Uninstaller is an open-source program, bulk program uninstaller with advanced automation. It excels at removing large amounts of applications with minimal to no user input, while requiring next to no technical knowledge. It can detect most applications and games (even portable or not registered), clean up leftovers, force uninstall, automatically uninstall according to premade lists, and much more.

Link for the download:

https://www.bcuninstaller.com/
