Controller Features Explained

Understand hair triggers, remappable buttons, modular parts, gyro aiming and rumble before choosing a controller for your setup.

Controller Features

1. Hair trigger: shorter travel for faster firing, useful in shooters.

2. Macro / turbo functions: automate repeated button presses or combos.

3. Remappable buttons: customize which buttons do what.

4. Adjustable stick tension: change joystick resistance for precision or speed.

5. modularity: the ability to change the layout of a controller (Xbox (asymmetric)/PS (symm)/Custom). Or swap specific parts only, i.e joysticks.

6. Swappable face buttons: change button style or layout (Xbox/Switch).

7. Gyro controls: motion-based aiming or movement.

8. Rumble motors: mechanical components that create physical vibrations to improve immersion.
