Windows 11 Running Slow? Quick Fixes

A slow PC usually has one clear cause. These checks find it quickly, and none of them cost money.

  1. Restart and update. Restart the PC and install all pending updates in Settings, then Windows Update. Many slowdowns come from an update that is half installed.
  2. Find what uses the resources. Press Ctrl+Shift+Esc to open Task Manager. Sort by CPU, Memory and Disk to see what is heavy. Open the Startup apps tab and turn off what you don't need.
  3. Free some disk space. Keep at least 15 percent of the system drive free. Use Settings, System, Storage, and clean the temporary files.
  4. Check the drive. Windows should be on an SSD. Check the drive health with CrystalDiskInfo. A drive at 100 percent usage in Task Manager is a bad sign.
  5. Scan for malware. Open Windows Security and run a full scan. A Microsoft Defender Offline scan can also catch hidden threats.
  6. Set the power mode. Go to Settings, System, Power and choose Best performance. On a laptop, plug in the charger.

If it is still slow after this, back up your files and use Reset this PC. Or ask us first and we will look at the details with you.
