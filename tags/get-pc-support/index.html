How to Get PC Help on Discord

Find the right Relics Discord help channel for PC troubleshooting, choosing components or planning a build, then start your request.

Copy the full text, paste it into your Relics Discord help conversation and add your answers where relevant. Links to Discord channels require server membership.

Discord tag

Need Help with Your PC?

Open the appropriate Relics Discord help channel:

- PC building and upgrades: #PC building help

- Technical troubleshooting: #Technical support

- Peripherals: #Peripheral help

Run /getstarted in that channel, choose the relevant questionnaire and answer all questions in a single message. A specialist will help when available.
