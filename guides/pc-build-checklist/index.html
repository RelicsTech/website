PC Build Checklist Before You Buy

Check these points before you order, and share your list with us for a free second opinion.

  1. Set the budget and the use. Decide what the PC is for (gaming, work, both) and a total price. For gaming, spend most on the graphics card.
  2. Check the CPU socket. The CPU and motherboard must use the same socket, and the BIOS must support that CPU.
  3. Check the RAM type. The board is either DDR4 or DDR5. They don't fit each other. Two sticks are better than one for speed.
  4. Size the power supply. Use the graphics card maker's recommended wattage. Buy a known brand, because a cheap PSU can damage other parts.
  5. Check case fit. Check the graphics card length, CPU cooler height and radiator size against the case specs.
  6. Plan storage and cooling. Use an NVMe SSD for Windows. Make sure the case has airflow and the cooler suits the CPU.
